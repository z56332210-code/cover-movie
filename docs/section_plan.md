# 섹션 계획 (초안) — スロウダウナー

## 측정값
- 길이 2:23.33, **129.2 BPM** (0–50초 구간 127–130 사이로 약간 흔들림 → 비트 그리드는 고정 템포가 아니라 측정된 비트 위치 사용), 1마디 ≈ 1.86초
- 섹션 경계(마디 단위, 측정): 0.55 / 20.99 / 30.42 / 54.86 / 62.11 / 82.54 / 84.39 / 101.09 / 123.36 / 128.93 / 139.4(소리 끝)
- 악센트는 이론상 박이 아니라 측정된 타악 onset에 배치

## 전체 규칙
- **베이스 톤**: 모노크롬 (콘크리트/종이 그레인 텍스처, 레퍼런스처럼 HUD 모서리 프레임 + `SLOWDOWNER` 라벨)
- **포인트 색 3개만**: 핏빛 레드 `#C8102E`(붉은 실·사랑·아픔), 링거 시안 `#8FD3D8`(환자·약·차가움), 불씨 오렌지 `#E8772E`(C섹션 "火" 한정)
- **캐릭터**: 원본 컬러 PNG를 흑백(약간 차가운 톤)으로 사용. **마지막 하나가 되는 순간에만 원래 색이 돌아옴**
- **구도**: 원본 MV처럼 왼쪽 환자 / 오른쪽 간호사. 일본어 타이포는 둘 사이 중앙 칼럼 + 얼굴을 피한 영역에만
- **폰트**: 일본어 디스플레이 = Shippori Mincho B1 (레퍼런스의 붓 느낌 명조, 400~800), 액센트 = Dela Gothic One (후렴 펀치 단어 한정). 한국어 자막 = Pretendard 고정 스타일
- **한국어 자막**: 하단 안전영역(y 930–1010 @1080p) 고정, 흰색 + 얇은 외곽선, 페이드만. 이 띠에는 어떤 일본어/효과도 침범하지 않음
- **스토리 장치**: 환자↔간호사 사이의 **중앙 분할선**과 **붉은 실** 한 가닥. 곡이 진행될수록 분할선이 좁혀지고, 끝에서 사라지며 둘이 겹쳐 하나가 됨
